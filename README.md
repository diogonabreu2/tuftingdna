# Tufting DNA

Site vitrine de l’atelier Tufting DNA : portfolio de créations tuftées, présentation du savoir-faire, simulateur de prix et formulaire de demande de projet.

## Nouveautés

- Portfolio avec les 11 photos de projets fournies.
- Galerie responsive avec ouverture des créations en grand format et navigation précédent/suivant.
- Site disponible en **français, portugais et anglais** avec sélecteur FR / PT / EN.
- Liens directs vers Instagram et TikTok de Tufting DNA.
- Nouvelle section « Du dessin au tapis » pour expliquer le processus.
- Simulateur de prix conservé et traduit dans les trois langues.
- Formulaire de contact conservé avec Netlify Forms.

## Réseaux sociaux

- Instagram : https://www.instagram.com/tuftingdna/
- TikTok : https://www.tiktok.com/@tuftingdna_

## Technologies

- TanStack Start et React 19
- TypeScript et Vite
- Netlify Forms
- CSS responsive sur mesure
- Lucide React

## Développement local

Prérequis : Node.js 22 et pnpm.

```bash
pnpm install
pnpm dev
```

Le formulaire est détecté par Netlify grâce à `public/contact-form.html`. Les soumissions complètes se testent sur un déploiement Netlify.
